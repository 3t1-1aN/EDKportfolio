# Quick Setup Guide

## Installation Steps

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

## Customization Checklist

### Essential Updates

- [ ] Replace "YOUR NAME" in:
  - `components/Navbar.tsx` (line ~15)
  - `components/Hero.tsx` (line ~30)
  - `components/Footer.tsx` (line ~8)

- [ ] Update social media links in:
  - `components/Hero.tsx` (line ~20)
  - `components/Footer.tsx` (line ~12)

- [ ] Add your projects in `components/Projects.tsx` (line ~5)

- [ ] Update contact information in `components/Footer.tsx` (lines ~50-60)

- [ ] Customize FAQ content in `components/FAQ.tsx` (line ~7)

- [ ] Update testimonials in `components/Testimonials.tsx` (line ~5)

- [ ] Add your blog posts in `components/Blog.tsx` (line ~5)

- [ ] Update statistics in `components/Stats.tsx`

### Optional Enhancements

- [ ] Add your own images (replace Unsplash URLs)
- [ ] Customize colors in `tailwind.config.ts`
- [ ] Add more sections or modify existing ones
- [ ] Set up contact form functionality
- [ ] Add analytics tracking
- [ ] Configure SEO metadata in `app/layout.tsx`
